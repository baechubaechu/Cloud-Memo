## ★ 다음에 켜자마자 — 브라우저로 직접 확인 (새 작업보다 먼저)

2026-10-03 에 자동 저장·동기화·오프라인을 크게 고쳤다. 자동 검증은 스크립트로 입력을 넣고
요청을 강제로 실패시켜 흉내 낸 것이라, 아래는 **사람이 실제로 쳐 봐야** 한다. 하나라도
이상하면 새 기능보다 그것부터 고친다.

실행: `powershell.exe -ExecutionPolicy Bypass -File .\scripts\dev-all.ps1`
(Docker Desktop 이 안 뜨면 `wsl --shutdown` 후 다시 실행. API 를 고쳤는데 반영이 안 되면
uvicorn `--reload` 가 옛 코드를 잡고 있는 것 — API 창을 닫고 다시 띄운다.)

**2026-10-04 1차 확인 결과** — 통과: 노트 전환+Ctrl+Z(2), 버전 복원(4), 태그(5), 노트 삭제(6),
3초 안 동기화 반영(7 첫 항목), 본문 한글 자동 저장. 발견해서 고친 것: 제목이 한글 조합 중
멈추면 저장 안 됨, 렌더된 줄 위에 이미지를 끌어다 놓으면 새 탭으로 열림, 첨부 패널에서
제거해도 본문 마커가 남음, 새 노트 직후 본문 클릭 시 포커스가 제목으로 끌려감.
**남은 것: 아래 1·3·6(다시 확인), 7의 동시 편집, 8 전부, 그리고 "커서가 사라지는" 증상.**

1. **한글 입력** — 본문과 제목에서 빠르게 치다 1초 멈췄다 다시 치기를 반복. 마지막 글자가
   빠지거나 조합 중인 글자가 깨지지 않는지. "저장됨" 으로 돌아오는지.
2. **노트 전환 + Ctrl+Z** — A 에 쓰고 B 로 가서 Ctrl+Z. B 본문이 그대로인지.
3. **이미지 붙여넣기(Ctrl+V)·드래그** — 캐럿 위치에 들어가는지, 새로고침 후에도 보이는지.
4. **버전 복원** — 우측 패널 「버전」 에서 되돌리기. 본문이 바로 바뀌는지.
5. **태그** — 「+ 태그」 에 한글 이름 입력 후 Enter. 한 번만 만들어지는지(조합 Enter 중복 없음).
6. **삭제** — 노트 삭제(태그·첨부 달린 노트 포함), 첨부 패널 「제거」.
7. **동기화 (브라우저 두 개 또는 PC + 폰)**
   - 한쪽에서 고치면 3~4초 안에 다른 쪽 열린 노트에 반영되는지.
   - 양쪽에서 서로 다른 줄을 동시에 고쳐 둘 다 남는지. 같은 줄을 고쳤을 때 결과가 납득되는지.
   - **한글을 조합 중일 때** 다른 쪽 변경이 들어와도 입력이 깨지지 않는지.
   - 한쪽에서 노트 삭제·폴더 생성 → 다른 쪽 목록에 반영되는지.
9. **커서가 사라지는 증상** — 어떤 커서인지(글자 입력 캐럿 / 마우스 포인터), 언제인지
   (새 노트 직후, 이미지 줄 근처, 화면 공유 중에만) 적어 둘 것. 새 노트 직후 본문 클릭 시
   캐럿이 사라지던 원인 하나는 고쳤다. 그래도 남으면 재현 순서가 필요.
10. **기기 보관·잠금 (2026-10-04 추가)** — 로그아웃 후 로그인 화면에서 「이 기기에 노트 보관」
    을 켜고 들어가기 → 새로고침하면 「잠금 해제」 가 뜨는지 → 틀린 비밀번호 거절 →
    로그아웃 후 개발자 도구 Application 탭에서 IndexedDB·Local Storage 가 비었는지.
    체크를 끄고 로그인하면 IndexedDB 가 아예 안 생기는지. (개발 모드는 자동 로그인이
    잠금도 대신 풀어 주므로, 잠금 화면은 직접 로그아웃한 직후에만 보인다.)
8. **오프라인 (실제로 Wi-Fi 를 끄거나 API 창을 닫고)**
   - **「이 기기에 노트 보관」 을 켠 상태여야** 다른 노트를 열 수 있다 (꺼져 있으면 열린 노트만).
   - 상단에 오프라인 띠가 뜨고, 다른 노트를 열고 고칠 수 있는지.
   - 탭을 닫았다가 연결 후 다시 열면 고친 내용이 서버에 올라가 있는지.
   - 오프라인 중 다른 기기에서 같은 노트를 고친 뒤 재연결 → 둘 다 남는지.
   - 오프라인 중 다른 기기에서 그 노트를 **삭제** → 재연결 시 「(복구)」 노트로 살아나는지.

확인한 항목은 [`ROADMAP_TECH.md`](./ROADMAP_TECH.md) **직접 확인 필요** 절에서 체크한다.
