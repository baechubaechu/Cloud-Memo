## 다음 구현 우선순위 (§0)

지금 앱의 완성도를 가장 빠르게 올릴 순서. 대형 구조 변경보다, 현재 에디터와
사이드바/검색 흐름 위에 바로 얹을 수 있는 기능을 우선한다.

1. **체크리스트 클릭 토글 + 모든 할 일 모아보기**
   - `- [ ]`, `- [x]` 를 실제 체크박스처럼 클릭해서 토글.
   - 전체 노트의 미완료 항목을 한 화면에 모아 보고, 클릭하면 해당 노트로 이동.
2. **명령 팔레트 + 슬래시 커맨드 + 사용자 지정 단축키**
   - 명령 팔레트: `Ctrl+K` / `Ctrl+P` 로 앱 명령 실행.
   - 슬래시 커맨드: 본문에서 `/` 로 체크리스트, 이미지, 그림, 제목 등을 삽입.
   - **사용자 지정 단축키**: `Ctrl+Z` 등 기본은 고정, `Shift+Enter` → 특정 노트
     이동 같은 **추가 바인딩**은 설정에서 지정. 상세는 **단축키** 절.
3. **위키링크 백링크 패널**
   - 본문 위키링크 자동완성은 `wikilinkExtension.ts` (CodeMirror autocomplete 기반)
     으로 재설계 완료. 다음 단계는 노트별 backlinks 패널 / "이 노트를 참조하는 노트"
     집계 / 깨진 링크 표시.
4. **데일리 노트**
   - 오늘 날짜 노트를 빠르게 열고, 날짜 링크/캘린더 기능의 기반으로 사용.
5. **노트 리스트 정렬 옵션**
   - 수정일 / 생성일 / 제목 순, 오름차순/내림차순, 폴더별 기본값.
6. **단어·글자 수 / 읽기 시간 + 단축키 도움말**
   - 구현 범위가 작고 매일 보이는 체감 품질 개선.
7. **단일 노트 export**
   - Markdown / PDF. PDF 는 그림 오버레이와 이미지 합성까지 고려.
8. **Obsidian 볼트 이식 (import)**
   - 기존 `.md` 볼트·폴더 구조를 CloudMemo 노트/폴더로 가져오기. 상세는 아래 절.
9. **다크 모드**
   - 시스템 설정 연동 + 수동 토글.
10. **Phase 3 v2 / STT / TTS / AI / 협업**
   - 위 기본 생산성 기능을 다듬은 뒤 큰 기능으로 이동.

## 편집 생산성

- [ ] **명령 팔레트**
  - `Ctrl+K` 또는 `Ctrl+P` 로 여는 앱 전체 명령 검색창.
  - 새 노트, 오늘 노트 열기, 그리기 모드, 이미지 삽입, export, 단축키 도움말
    같은 명령을 키보드로 실행.
  - 팔레트에 뜨는 명령과 **사용자 지정 단축키**가 같은 `command id` 를 가리키게
    통합(아래 **단축키** 절).
- [ ] **슬래시 커맨드**
  - 본문에서 `/` 를 입력하면 삽입 메뉴 표시.
  - 예: `/체크리스트`, `/제목`, `/이미지`, `/그림`, `/음성`, `/날짜`.
  - Notion 스타일 UX. 명령이 많아졌을 때 유용.
- [ ] **콜아웃 / 인용 블럭 (보류)**
  - 예: `> [!warning]` 같은 문법을 경고/정보 박스로 렌더.
  - 체크박스와 직접 충돌하지는 않음. 체크박스는 `- [ ]`, 콜아웃은 `>` 로
    시작해 문법 prefix 가 다르다.
  - 다만 지금 우선순위는 낮으므로 보류.
- [ ] **코드블럭 신택스 하이라이트 (보류/낮음)**
  - 개발 노트를 많이 쓸 때 코드 색상 표시.
  - 현재 앱 방향에서는 필수성이 낮아 우선순위에서 제외.

## 단축키 (기본 + 사용자 지정)

**기본 단축키**는 앱·에디터에 내장하고 **수정 불가**(또는 OS 표준과 동일하게
고정). **추가 단축키**만 사용자가 조합을 지정해 **앱 명령**에 연결한다.
(옵시디언 Hotkeys / VS Code keybindings 와 유사.)

### 기본으로 포함 (고정·문서화)

- [x] **에디터** — `editorKeymaps.ts` 등: `Ctrl+Z` / `Ctrl+Y` undo·redo, 화살표·
  삭제, 인용 블록 Enter 등 CodeMirror keymap.
- [x] **앱** — `Ctrl+K` / `Ctrl+P` 명령 팔레트, 슬래시 메뉴 `↑↓`·Enter·Esc
  (`workbenchCommands.ts` / `CommandPalette.tsx`).
- [ ] **단축키 도움말**에 위 기본 목록을 **읽기 전용**으로 전부 노출(아래 보내기 절).

기본 키는 **사용자가 덮어쓰지 못함** — `Ctrl+Z` 가 다른 동작으로 바뀌면
회귀·지원 부담이 큼.

### 사용자 지정 단축키 (백로그)

- [ ] **설정 UI**
  - 설정(또는 `?` 도움말)에서 “단축키” 탭: 조합 기록(예: `Shift+Enter`) → 동작 선택.
  - 충돌 시 경고(이미 쓰는 조합·브라우저 예약 키).
- [ ] **연결 가능한 동작 (1차)**
  - `workbenchCommands` / 명령 팔레트와 동일한 **command id** 목록에서 선택.
  - 예: 새 노트, 오늘 노트 열기, 검색 포커스, 그리기 모드 토글, 사이드바 접기,
    우측 패널(첨부/할 일/버전) 열기.
- [ ] **연결 가능한 동작 (2차 — 페이지/노트 이동)**
  - **특정 노트 열기** — 노트 id 또는 제목(고정) 지정. 예: `Shift+Enter` →
    “인박스” 노트, “프로젝트 A” 노트.
  - **특정 폴더** 트리에서 선택·펼침.
  - **URL/딥링크** — `memo://note/{id}` 와 동일한 내비게이션(위젯·앱과 공유).
- [ ] **적용 범위(scope)**
  - **전역** — 에디터 밖(사이드바·목록 포커스)에서도 동작.
  - **에디터 포커스 시** — 본문 CodeMirror 안에서만(예: `Shift+Enter` 가 줄바꿈과
    충돌하면 “에디터에서만” 또는 chord `Ctrl+Shift+Enter` 권장).
  - **제목 input 포커스 시** — 제목 필드 전용 바인딩(선택).
- [ ] **저장**
  - 계정별 서버 저장(`user_settings.keybindings`) + 로컬 캐시; 기기마다 다를 수
    있음을 UI에 표시.
- [ ] **구현 메모**
  - 전역: `document` capture 단계 리스너 + command 디스패치.
  - 에디터: CodeMirror `Prec.highest` keymap 으로 사용자 map 병합
    ([`ROADMAP_TECH.md`](./ROADMAP_TECH.md) `editorKeymaps.ts`).
  - IME 조합 중·한글 입력 중에는 단축키 무시(제목/본문과 동일 정책).

### 검증

- [ ] 기본 `Ctrl+Z` 등은 사용자 map 추가 후에도 동작 유지.
- [ ] 사용자 `Shift+Enter` → 지정 노트 이동이 에디터/전역 scope 에서 기대대로.
- [ ] macOS `Cmd` vs Windows `Ctrl` 표기·실제 키 정규화.

## Obsidian 볼트 이식 (import)

Obsidian에서 쓰던 마크다운 볼트를 CloudMemo로 옮기는 기능. **export와 짝**이 되며,
온보딩·데이터 이전 수요를 담당한다. (웹 데스크톱에서 먼저 제공, 대용량은
백그라운드·진행률 UI 고려.)

### 범위 (1차 — MVP)

- [ ] **볼트 루트 선택**
  - 로컬 폴더 경로 지정(데스크톱) 또는 `.zip` 업로드(서버 일괄 처리 시).
  - `.obsidian/` 설정 폴더는 기본 **무시**(플러그인·테마는 이식 대상 아님).
- [ ] **노트 생성**
  - `.md` 파일 → CloudMemo `Note` (`title` + `content`).
  - 제목: 파일명(확장자 제외) 또는 YAML frontmatter `title` / 본문 첫 `#` 제목
    우선순위 규칙 문서화.
  - 상대 경로의 폴더 → CloudMemo `folder` 트리(중첩 `parent_id` 유지).
- [ ] **위키링크·내부 링크**
  - `[[노트]]`, `[[노트|표시]]`, `[[노트#헤딩]]` 는 가능한 범위에서 **본문
    문자열 그대로** 보존(이미 `[[...]]` 편집·이동 지원).
  - Obsidian 전용 `![[embed]]` / `![[image.png]]` 는 1차는 첨부 마커 또는
    일반 마크다운 이미지로 변환 규칙 정의.
- [ ] **첨부·이미지**
  - 같은 폴더·`attachments/` 등 Obsidian 관례 경로의 파일을 업로드 API로
    `Attachment` 로 연결하고, 본문 경로를 CloudMemo 마커/URL 형식으로 치환.
- [ ] **태그·메타(선택)**
  - frontmatter `tags:` → CloudMemo 태그 연결.
  - `created` / `modified` 는 서버 필드와 충돌 시 “가져온 시각” vs “원본 시각”
    정책 결정(기본은 import 시각, 옵션으로 원본 반영).

### 범위 (2차 — 품질)

- [ ] **중복·재실행**
  - 같은 경로/제목 재 import 시 스킵·덮어쓰기·새 노트로 복제 중 사용자 선택.
- [ ] **대용량 볼트**
  - 수천 파일 진행률·취소·실패 목록(로그 다운로드).
- [ ] **검증 리포트**
  - import 후 요약: 노트 N개, 폴더 M개, 첨부 K개, 변환 실패/스킵 L건.
- [ ] **Obsidian 전용 문법**
  - 콜아웃 `> [!note]`, 데이터뷰 블록 등은 1차 **원문 보존** 또는 HTML 주석
    유지; 렌더 호환은 별도 로드맵(콜아웃 절)과 연계.

### 기술·연동 메모

- 백엔드: 일괄 `createNote` / `createFolder` / `uploadAttachment` API 또는
  전용 `POST /api/import/obsidian` (트랜잭션·레이트 제한).
- 프런트: 설정/사이드바에 “Obsidian에서 가져오기” 마법사; 로컬 폴더는
  **데스크톱 웹** 또는 추후 **네이티브 앱** 파일 피커.
- [`ROADMAP_TECH.md`](./ROADMAP_TECH.md): import 중 autosave·위키링크 대량 생성 시
  성능·회귀 점검 항목으로 추가 검토.

## 웹(데스크톱) · 네이티브 앱(모바일·태블릿)

**전략:** 휴대폰·태블릿은 **별도 앱**으로 제공한다. 같은 API·인증을 쓰되,
터치·오프라인·OS 권한 등은 앱 쪽에서 맞춘다. 웹(`web/`)은 **데스크톱 브라우저
중심**으로 품질을 맞추고, 좁은 창에서의 동작은 “읽기/보조” 수준으로 둘지
별도 결정한다.

### 웹 — 브라우저 호환·검증 (백로그)

- [ ] **브라우저 최소선**
  - Chromium 계열(Chrome, **Edge**), Safari(macOS), Firefox 중 공식 지원 조합을
    문서화하고 CI/수동으로 그 조합만 우선 검증.
- [ ] **데스크톱 UX**
  - 해상도·멀티 모니터, 키보드 단축키, 휠/트랙패드 스크롤.

## 동기화 · 사용자 허브

**원칙:** 벤더 메모 SaaS·제3자 동기화 저장소(Dropbox, iCloud, S3 등) 없음.  
동기화는 **사용자 소유 허브**(집 저전력 기기, 본인 VPS/VM)와 기기 간 **앱 내장 싱크**로만
이루어진다. 배포 프로필: [`deploy/README.md`](../deploy/README.md).

### 백로그

- [ ] **허브 연결 설정**
  - 최초 실행: 허브 주소(URL 또는 Tailscale 호스트), 인증, 연결 테스트.
  - 프로필별 가이드(`deploy/hub`, `deploy/vps`)와 동일한 API 계약.
- [ ] **자동 동기화 켜기 / 끄기**
  - 설정(또는 상단/사이드바)에 **「자동 동기화」** 토글.
  - **켜짐:** 편집·첨부 저장 후 백그라운드로 허브와 주기적/이벤트 기반 동기화.
    밖에서도 항상 최신 상태 유지(허브·네트워크 가능 시).
  - **꺼짐:** 해당 기기는 **로컬만** 읽기·쓰기. 허브로 push/pull 하지 않음.
    수동 **「지금 동기화」** 버튼으로 한 번만 맞추기(선택).
  - 상태 표시: 동기화 중 / 최신 / 오프라인 / 일시정지(자동 끔) / 오류.
  - 기기별 저장(폰은 끄고 노트북만 켜기 등). 모바일 앱에서는 배터리·데이터
    고려해 기본값·설명 문구 제공.
- [ ] **오프라인 편집 큐**
  - 자동 동기화가 꺼져 있거나 네트워크 없을 때 로컬 변경 보관.
  - 다시 켜거나 연결 복구 시 허브와 충돌 해결(버전·타임스탬프 정책은 구현 시 ADR).
- [ ] **충돌 UI**
  - 같은 노트를 두 기기에서 수정한 경우 사용자에게 선택 또는 병합 안내.

### 구현 순서 (권장)

1. 허브 단일 인스턴스 + 클라이언트 API 연동(웹·앱 공통).
2. **자동 동기화 토글** + 수동 동기화 + 상태 표시.
3. 오프라인 큐·충돌 처리.

## 홈 · 바탕화면 위젯 (Rainmeter 스타일)

**Rainmeter**처럼 바탕화면·홈 화면에 항상 떠 있거나 한 번에 보이는 **작은 패널**.
본 앱을 매번 열지 않고 오늘 노트 확인·즉시 메모·일정 훑기를 한다. 웹 브라우저가
아니라 **데스크톱 클라이언트(Windows/macOS) + 네이티브 앱(iOS/Android)** 에서
구현한다.

### 위젯 종류 (백로그)

- [ ] **오늘 노트**
  - `YYYY-MM-DD` 데일리 노트 제목·본문 일부(마크다운 plain 요약) 표시.
  - 탭/클릭 → 해당 노트를 앱·웹에서 열기(딥링크 `memo://note/{id}` 등).
  - §0 **데일리 노트**·[`ROADMAP_PLATFORM.md`](./ROADMAP_PLATFORM.md) 일정 절과 연동.
- [ ] **빠른 메모**
  - 한 줄~짧은 텍스트 입력 → 지정 폴더/인박스 노트에 append 또는 새 노트 생성.
  - 오프라인 큐 후 동기(앱·데스크톱 공통).
  - Windows: Rainmeter 스킨처럼 **항상 위** 작은 입력창 옵션.
- [ ] **캘린더**
  - 월/주 미니 뷰: 데일리 노트가 있는 날, `due:`·체크리스트 마감(있을 경우) 표시.
  - 날짜 탭 → 그날 데일리 노트 또는 노트 목록.
  - 풀 캘린더 UI는 플랫폼 로드맵 **일정 / 캘린더** 와 단계적으로 합침.

### 플랫폼별 (백로그)

- [ ] **Windows**
  - Rainmeter 유사: 투명·드래그 가능 데스크톱 오버레이, 다중 모니터, DPI.
  - Win11 **위젯 보드** 연동은 2차(스토어·API 제약 별도 조사).
- [ ] **macOS**
  - Notification Center / **WidgetKit** (오늘 노트·빠른 메모 위주).
- [ ] **iOS / Android**
  - 홈 스크린·(선택) 잠금 화면 위젯, 위젯 갱신 주기·배터리 정책.
- [ ] **공통**
  - 위젯 전용 **경량 API** 또는 캐시(토큰·오늘 노트 id·캘린더 요약 JSON).
  - 테마: 라이트/다크·투명도(데스크톱).

### 구현 순서 (권장)

1. 데일리 노트 API·딥링크 확정 → **오늘 노트** 위젯 1종.
2. **빠른 메모** (capture endpoint + 오프라인 큐).
3. **캘린더** 미니 뷰(플랫폼 일정 절과 스펙 공유).
4. Windows Rainmeter 스타일 오버레이 vs 모바일 홈 위젯을 플랫폼 팀이 병렬.

### 참고 서비스 분석 (TickTick · 스케두)

데스크톱·홈 위젯 설계 시 벤치마크. (2026-05 분석)

#### TickTick

- **다운로드:** [ticktick.com/download](https://ticktick.com/download) — iOS/Android/Windows/macOS/Linux/Extension.
- **포지션:** 할 일·캘린더·습관·포모도로를 한 계정으로 묶은 **생산성 슈트**. 위젯은 메인 앱의
  작은 창이며, Rainmeter처럼 바탕화면만 사는 단일 패널이 아님.
- **Windows 데스크톱 위젯** ([Help: Widgets](https://help.ticktick.com/articles/7055780404896202752))
  - 작업 표시줄 아이콘 우클릭 → *Add Desktop Widgets*.
  - **Task Widget** — 목록 보기·완료 체크.
  - **Calendar Widget** — 오늘·일간·월간 일정.
  - **Eisenhower Matrix Widget** — 긴급/중요 분류(참고만).
- **Desktop Sticky Notes** ([Help: Sticky Notes](https://help.ticktick.com/articles/7055780431722971136))
  - 태스크 → “Open as Sticky Note”, 항상 위·F12 고정, 전역 단축키로 새 메모.
  - 설정 → Hotkeys → Global Actions → Add Sticky Note.
- **전역 단축키 예** (Windows): `Ctrl+Shift+A` 빠른 추가, `Ctrl+Alt+T` 오늘 목록,
  `Ctrl+Alt+C` 캘린더 — CloudMemo **사용자 지정 단축키**·command id 설계 시 참고.
- **모바일:** 홈·잠금 화면 위젯, iOS 18 Control Center 컨트롤 — 네이티브 앱 위젯 로드맵과 동일 축.
- **CloudMemo에 가져올 것**
  - 위젯을 **오늘 노트 / 빠른 입력 / 월·일 캘린더** 등 3~4종으로 분리해 선택 추가.
  - 위젯에서 체크리스트 토글(플랫폼 허용 시).
  - **Sticky = 특정 노트를 데스크톱에 고정**(빠른 메모 + 인박스 노트 핀).
  - 팔레트·위젯·단축키가 같은 **command id** 를 가리키게 통합.

#### 스케두 (Schedo Calendar)

- **소개:** [Schedo Calendar – 소셜프렌즈](https://sfsoftware.co.kr/schedo-calendar/) —
  Windows **바탕화면 캘린더 오버레이**. Rainmeter에 가깝고, 구글 캘린더 연동.
- **Rainmeter 스타일 UX**
  - 투명도·**위치 고정**, 모서리 드래그로 스케일 조절, 화이트/다크 테마.
  - **숨기기/보이기** `Ctrl+Shift+X`, 종료 `Ctrl+Shift+Q`.
  - 부팅 시 트레이 아이콘 실행, “항상 그 자리” 데스크톱 상주.
- **일정 UX**
  - **더블클릭**으로 일정 입력(메모장처럼), 업무/개인/생일 등 캘린더 분리.
  - 종일·시간대, 반복, 팝업/이메일 알림.
  - 구글 캘린더 실시간 동기화, 우측 확장창에서 일·주·월 리스트·검색.
- **TickTick과 차이**

  | | TickTick | 스케두 |
  |---|----------|--------|
  | 데이터 | 자체 할 일·습관 DB | 구글 캘린더 + 로컬 UI |
  | 노트·위키 | Sticky·태스크 설명 수준 | 일정 메모·상세 필드 |
  | 플랫폼 | 전 플랫폼 | **Windows 데스크톱 중심** |

- **CloudMemo에 가져올 것**
  - 투명·드래그·크기·**재시작 후 위치 복원**, 전역 단축키로 표시/숨김.
  - 월/주/일 미니 뷰 + **날짜 더블클릭 → 그날 데일리 노트** 열기.
  - 외부 구글 대신 **CloudMemo API**(`YYYY-MM-DD` 노트, `due:`, 체크리스트)가 소스 — 차별점.

#### CloudMemo 위젯 설계 합성

```
┌─────────────────────────────────────────┐
│  Rainmeter 층 (스케두 참고)              │
│  · 투명 캘린더 패널, 위치 고정, 표시/숨김  │
│  · 월간+오늘, 날짜 탭 → 데일리 노트        │
├─────────────────────────────────────────┤
│  생산성 층 (TickTick 참고)               │
│  · 작은 “빠른 메모” 입력(항상 위 옵션)     │
│  · 핀된 노트 1장 = Sticky                 │
│  · 위젯에서 체크리스트 토글 (2차)          │
├─────────────────────────────────────────┤
│  공통                                    │
│  · memo://note/{id} 딥링크               │
│  · 경량 API (오늘 노트 요약, 캘린더 JSON)  │
└─────────────────────────────────────────┘
```

| 로드맵 위젯 | TickTick에서 | 스케두에서 |
|-------------|--------------|------------|
| **오늘 노트** | Today's Calendar, Today 스마트 리스트 | 월간+오늘 칸, 더블클릭 입력 |
| **빠른 메모** | Sticky, `Ctrl+Shift+A` | — (CloudMemo 강점) |
| **캘린더** | Daily / Monthly 위젯 | 일·주·월 리스트, 월뷰 |

**권장 구현 순서(재확인):** 스케두식 **Windows 오버레이 캘린더** 1종 → TickTick식
**빠른 입력·핀 노트** → iOS/Android 홈 위젯(네이티브 앱).
